# 🍻 엔빵 - 술자리 N빵 계산기

술자리에서 복잡한 정산을 1분 만에 끝내고 카톡방으로 바로 공유하는 웹사이트입니다.
서버·빌드가 없는 정적 사이트라 `index.html`을 열기만 하면 실행되고, GitHub Pages·Netlify·Vercel 등에 그대로 올릴 수 있습니다.

## 기능
- **술 안 마신 사람 제외**: 🍺를 끄면 그 사람은 술값을 안 내고 음식값만 냅니다
- **차수별 참석자**: 1차·2차·3차마다 온 사람을 따로 고르면, 그 차수에 온 사람끼리만 나눕니다
- **가중치**: 선배 1.5배, 막내 0.8배처럼 사람마다 비율을 다르게 정합니다
- **고정 금액**: "내가 10만원 낼게" → 그 사람은 정해진 금액만 내고, 남은 금액을 나머지가 원래 비율대로 나눕니다
- **차수별 결제자**: 1차는 A가, 2차는 B가 결제했어도 서로 상계해 송금 횟수를 최소로 줄입니다
- **송금 단위 올림**: 100원/1,000원 단위로 올리고, 남는 차액은 총무가 덜 내는 방식으로 맞춥니다
- **카톡 공유**: 정산 결과 전체가 링크 하나에 담깁니다. 링크를 받은 사람은 결과를 보고 "나도 계산하기"로 바로 써볼 수 있어 자연스럽게 퍼집니다

## 파일
| 파일 | 역할 |
| --- | --- |
| `calc.js` | 계산 로직 (분배, 고정 금액, 올림, 송금 최소화) |
| `app.js` | 화면, 링크 인코딩, 공유 |
| `calc.test.js` | 계산 테스트: `node dutch-pay/calc.test.js` |
| `og-image.png` | 카톡/SNS 링크 미리보기 이미지 (1200×630) |

## 배포 후 할 일 (수익화·확산)
1. **도메인 연결**: 짧고 기억하기 쉬운 주소일수록 공유가 잘 됩니다
2. **링크 미리보기**: `index.html`의 `og:image`를 `https://내도메인/og-image.png`처럼 절대주소로 바꾸고 `og:url`을 추가합니다
3. **카카오톡 공유 버튼**: [Kakao Developers](https://developers.kakao.com)에서 앱을 만들고, 플랫폼 > Web에 도메인을 등록한 뒤 JavaScript 키를 `app.js` 맨 위 `KAKAO_JS_KEY`에 넣습니다. 키가 없으면 휴대폰 공유창이나 텍스트 복사로 동작합니다
4. **광고**: Google AdSense 승인 후 `index.html`의 `#adSlot` 안에 광고 코드를 넣습니다 (결과 바로 아래라 노출이 잘 됩니다)
5. **검색 노출**: Google Search Console, 네이버 서치어드바이저에 사이트를 등록합니다
