# 🍻 엔빵 - 술자리 N빵 계산기

술자리에서 복잡한 정산을 1분 만에 끝내고 카톡방에 링크로 보내는 웹사이트입니다.
서버·빌드가 없는 정적 사이트라 `index.html`을 열기만 하면 실행되고, GitHub Pages·Netlify·Vercel 등에 그대로 올릴 수 있습니다.

## 기능
**계산**
- **술 안 마신 사람 제외**: 🍺를 끄면 술값은 안 내고 음식값만 냅니다
- **차수별 참석자**: 1차·2차·3차마다 온 사람끼리만 나눕니다
- **술 종류별 단가**: 소주 5,000원 × 6병, 맥주 5,000원 × 4병처럼 넣으면 소주는 소주 마신 사람끼리, 맥주는 맥주 마신 사람끼리 나눕니다
- **마신 잔 수**: +/−로 잔 수를 세면 그 술값을 잔 수대로 나누고, 총 잔 수와 👑 오늘의 주당을 보여줍니다
- **가중치 · 고정 금액**: 선배 1.5배, 막내 0.8배 / "내가 10만원 낼게"
- **차수별 결제자**: 결제한 사람이 여럿이어도 상계해서 송금 횟수를 최소로 줄입니다
- **끝전 처리**: 올림 후 총무가 덜 내기, 또는 🎯 룰렛으로 한 명에게 끝전 몰아주기

**공유 (방문자를 늘리는 장치)**
- **카톡방에 링크 보내기**: 금액 전체가 아니라 "정산 완료! 내 금액 확인하고 '보냈어요' 눌러주세요"와 사이트 링크를 보냅니다. 받은 사람이 모두 사이트에 들어오게 됩니다
- **나는 누구?**: 링크로 들어온 사람은 내 이름만 누르면 내 금액, 송금 버튼, '보냈어요' 버튼만 보입니다
- **송금 완료 체크**: 누가 보냈는지 진행률로 보여줍니다 (Firebase를 연결하면 모두에게 실시간 공유)
- **송금 바로가기**: 계좌·금액 한 번에 복사, 토스아이디(toss.me)·카카오페이 송금코드(qr.kakaopay.com) 링크
- **결과 이미지 카드**: 정산서를 이미지로 만들어 저장·공유합니다. 아래에 사이트 주소가 들어갑니다

## 파일
| 파일 | 역할 |
| --- | --- |
| `calc.js` | 계산 로직 (분배, 술 종류별, 고정 금액, 끝전, 송금 최소화) |
| `app.js` | 화면, 링크 인코딩, 공유, 송금 체크, 이미지 카드, 룰렛 |

## 배포 후 할 일
1. **사이트 공개**: GitHub 저장소 Settings → Pages에서 브랜치를 고르면 `https://<아이디>.github.io/travel-site/dutch-pay/`로 열립니다. 짧은 도메인을 연결하면 더 좋습니다
2. **링크 미리보기**: `index.html`의 `og:image`를 `https://내주소/og-image.png`처럼 절대주소로 바꾸고 `og:url`을 추가합니다
3. **카카오톡 공유 카드**: [Kakao Developers](https://developers.kakao.com)에서 앱을 만들고 플랫폼 > Web에 사이트 도메인을 등록한 뒤, JavaScript 키를 `app.js` 맨 위 `KAKAO_JS_KEY`에 넣습니다
4. **송금 체크 공유 (Firebase, 무료)**: [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 → Realtime Database를 만들고, 주소를 `app.js`의 `FIREBASE_DB_URL`에 넣습니다. 규칙은 아래처럼 정산별 체크만 읽고 쓰게 제한하세요
   ```json
   {
     "rules": {
       "bills": {
         "$bill": {
           "paid": {
             ".read": true,
             "$key": { ".write": true, ".validate": "newData.isBoolean()" }
           }
         }
       }
     }
   }
   ```
5. **광고**: Google AdSense 승인 후 `index.html`의 `#adSlot` 안에 광고 코드를 넣습니다
6. **검색 노출**: Google Search Console, 네이버 서치어드바이저에 사이트를 등록합니다
